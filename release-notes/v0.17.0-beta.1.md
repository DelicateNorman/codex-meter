# Codex Meter Desktop preview

This release adds the first public macOS desktop preview while keeping the
native CLI available on Linux, macOS, and Windows.

## macOS desktop downloads

| Mac | Download |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `codex-meter-desktop-macos-arm64.dmg` |
| Intel | `codex-meter-desktop-macos-x86_64.dmg` |

Open the DMG and drag **Codex Meter** into Applications. The desktop preview
uses the same `~/.codex-meter` history as the CLI; installing, updating, or
removing the app does not delete that directory.

> **Unsigned preview:** these DMGs are not Developer ID signed or notarized.
> On first launch, right-click Codex Meter and choose **Open**. If macOS still
> blocks it, use **System Settings → Privacy & Security → Open Anyway**. Verify
> the download against the included `SHA256SUMS` before opening it.

## Highlights

- Native macOS window using Tauri and the system WebView.
- Live Codex/Spark seven-day allowance bars.
- Today, Week, Month, and All time views with project filtering.
- Response health, model breakdowns, recent sessions, and refresh progress.
- Metadata-only local and SSH collection with the same privacy filters as the
  Rust CLI; prompts, responses, reasoning text, commands, and tool output are
  not stored by Codex Meter.
- Finder-safe Codex CLI discovery across common Homebrew, local-bin, Volta,
  FNM, npm-global, and NVM locations.

The CLI assets in this release remain one-file native executables. The Unix and
PowerShell installers verify checksums and preserve existing history during
installation, upgrade, and rollback.
