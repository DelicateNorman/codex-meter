# Homebrew tap for Codex Meter

This directory is the source for the public
[`DelicateNorman/homebrew-codex-meter`](https://github.com/DelicateNorman/homebrew-codex-meter)
tap.

Install the stable CLI release:

```bash
brew install DelicateNorman/codex-meter/codex-meter
```

Upgrade or remove it with ordinary Homebrew commands:

```bash
brew upgrade codex-meter
brew uninstall codex-meter
```

The formula downloads the architecture-specific, checksum-pinned executable
from the matching GitHub Release. It does not create, modify, or delete the
usage database under `~/.codex-meter`.
